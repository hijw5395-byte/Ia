# Biblia – Palabra de Dios

Aplicación Android gratuita, sin anuncios y sin permisos de Internet. Incluye versículo diario, favoritos y lectura completa de la Reina-Valera 1909 sin conexión.

Cada cambio en main ejecuta GitHub Actions. Al terminar, el APK app-debug.apk queda disponible en el artefacto Biblia-Palabra-de-Dios-APK durante 30 días.

- Versículo del día (cambia cada día).
- Guardar y quitar favoritos.
- Reina-Valera 1909 completa, descargada durante la compilación e incluida en la aplicación.
- Sin publicidad, analítica ni conexión de red en tiempo de ejecución.

Fuente: https://ebible.org/spaRV1909/
